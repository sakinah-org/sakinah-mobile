## Features
- **Bottom navigation shell** via `MainPage` + `MainBottomNavigationBar` ready to host modules.
- **Centralized routing** with route constants and fade/slide transitions.
- **Theming and localization** toggled via `SettingsCubit`.
- **Environment-based configuration** using `.env.*` files (`lib/configurations/app_env.dart`).
- **Network layer** with Dio, structured logging, and interceptors (`lib/network/`).
- **Utility handlers** for permissions, file/image picking, opening files, and translation support.
- **Preconfigured assets** for images, icons, fonts, and language files.

## Tech Stack
- **Flutter** SDK 3.5+
- **State**: `flutter_bloc`, `hydrated_bloc` (ready to integrate)
- **HTTP**: `dio`
- **Localization**: `flutter_localizations` + custom `translation_handler`
- **Storage/Device**: `hive_flutter`, `path_provider`, `permission_handler`, `image_picker`, `file_picker`, `open_file`
- **UI**: `flutter_svg`, `cached_network_image`, `shimmer_animation`, `carousel_slider`, `table_calendar`, `video_player`, `flutter_html`, etc.

See `pubspec.yaml` for the complete dependency list.

## Architecture
- `lib/configurations/`: Environment, states, endpoints, translation keys.
- `lib/navigation/`: Route constants and `RouteGenerator` with shared transitions.
- `lib/network/`: `DioClient`, interceptors, and `RequestInstructions`.
- `lib/shared/`: Global blocs, models, and reusable widgets.
- `lib/features/`: Feature-first structure; `features/main` contains the navigation shell.
- `lib/handlers/`: Cross-cutting concerns (permissions, translation, pickers, encryption).
- `lib/utils/`: Assets keys and theming (`app_theme.dart`, `app_colors.dart`).

## Environment Configuration
Handled by `lib/configurations/app_env.dart` using `flutter_dotenv`.

Create the following files at the project root (same level as `pubspec.yaml`):
- `.env.development`
- `.env.staging`
- `.env.production`

Each file should define:
```
BASE_URL=https://api.example.com
ALLOWED_DOMAINS=example.com,api.example.com
```

`main.dart` sets `env = 'dev'` by default, which maps to `.env.development` via `AppEnv.fromEnvironment()`.

Note: Although there is an `assets/env/` directory, `AppEnv` loads environment from root `.env.*` files by default. Do not commit secrets.

## Getting Started
- **Install** Flutter 3.5+ and platform toolchains.
- **Install deps**: `flutter pub get`.
- **Configure** `.env.*` files as needed.
- **Ensure** platform prerequisites (Android SDK, Xcode) are set up.

## Running the App
- Run on a device/emulator: `flutter run`

On launch:
- Theme derives from `SettingsCubit.isDarkMode`.
- Locale derives from `SettingsCubit.locale`.
- Routes are generated by `generateRoute()` with `initialRoute = AppRoutes.login`.

Tip: Swap to `AppRoutes.main` when your login flow is ready.

## Building for Release
- Android APK: `flutter build apk --release`
- Android AppBundle: `flutter build appbundle --release`
- iOS (macOS): `flutter build ios --release`

Android notes:
- `android/app/src/main/AndroidManifest.xml` has `INTERNET` and app label set to "Academy Commerce". Adjust as needed.

## Localization (i18n)
- Language files: `assets/lang/en.json`, `assets/lang/ar.json`
- Keys: `lib/configurations/app_translation_keys.dart`
- Loader: `lib/handlers/translation_handler.dart` with `AppLocalizationsDelegate`
- In `main.dart`, the delegate is commented. To enable, uncomment `AppLocalizationsDelegate()` and ensure assets are declared in `pubspec.yaml`.

Example `en.json`:
```
{
  "settings": "Settings"
}
```

## State Management
- `SettingsCubit` manages:
  - Dark mode: `toggleDarkMode()` (TODO: persist)
  - Locale toggle: `toggleLocale()` between `en` and `ar`
- Add feature-specific Cubits/BLoCs under `lib/features/...` or shared ones under `lib/shared/bloc/`.

## Networking
- `DioClient` (`lib/network/network_handler.dart`) uses `AppEnv.instance.baseUrl` and logging interceptors.
- Pretty logging via `lib/network/dio_interceptor.dart` with `logger`.
- Add auth headers/tokens in `onRequest` or a custom interceptor.

## Security/Encryption
- `AESEncryptor` provides symmetric encryption utilities.
- Important: Replace the sample hardcoded key with a secure key management strategy before production.

## Troubleshooting
- **AppEnv not initialized**: Ensure `AppEnv.init(env)` is called before networking (it is in `main.dart`), and that your `.env.*` files exist and define `BASE_URL`.
- **Translations missing**: Register `AppLocalizationsDelegate`, confirm `assets/lang/*.json` are included in `pubspec.yaml`, and keys exist.
- **Android network issues**: Confirm `android.permission.INTERNET` in `AndroidManifest.xml` (already present) and device connectivity.
